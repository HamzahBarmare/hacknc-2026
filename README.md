# hacknc-2026 — iMessage group-chat summarizer

A local [Spectrum](https://photon.codes/docs/spectrum-ts) agent that summarizes
your iMessage group chats.

It runs on your own Mac using the **local iMessage provider**
(`@spectrum-ts/imessage-local`), which reads your Messages database
(`~/Library/Messages/chat.db`) and sends from your own iMessage account — no
cloud line, `PROJECT_ID`, or `PROJECT_SECRET` required.

## What it does

- Buffers inbound group messages in a local SQLite file (`messages.db`).
- When someone in a group says **"summarize past 24 hours"**, it DMs that
  person a recap generated by an OpenAI-compatible model.
- Understands time windows like `summarize past 2 hours`, `30 minutes`, `3 days`
  (defaults to 24 hours).
- Retains messages for **7 days**; older messages are pruned hourly.
- In a DM, reply `ping` for a health check.
- Guards against macOS echoing your own outgoing messages back into the
  database, and can restrict who may trigger a summary.

## Requirements

- **macOS** with Messages signed in.
- **Node ≥ 22.5** (uses `node:sqlite` and `process.loadEnvFile`).
- **Full Disk Access** for your terminal, to read `~/Library/Messages/chat.db`.
- **Automation** permission for your terminal, to send via Messages.
- An API key for an OpenAI-compatible provider (Gemini, Groq, OpenRouter, …).

## Setup

```sh
npm install
cp .env.example .env   # then fill in the values
```

Configure `.env` (see `.env.example` for all options):

```sh
OPENAI_API_KEY=...
OPENAI_BASE_URL=https://generativelanguage.googleapis.com/v1beta/openai/
OPENAI_MODEL=gemini-flash-latest

# Optional
ALLOWED_SENDERS=+15551234567,me@example.com   # who may trigger summaries
TIMEZONE=America/New_York
DB_PATH=messages.db
```

## Run

```sh
npm run start   # run once
npm run dev     # watch mode
```

Then, in an iMessage group, send `summarize past 24 hours` from an allowed
sender. The bot replies with a summary via DM.

## Privacy

- Your messages are read from the local Messages database and stored in
  `messages.db` (both stay on your machine).
- The summary transcript is sent to the configured model provider to generate
  the recap — choose a provider whose data policy you're comfortable with.
- `.env` and `messages.db` are gitignored; never commit them.
